# Validation guide

Use the existing panel QA account or deterministic local preview, keeping their evidence separate. Open Administration → Checklists → edit photo object rules. Search `мяч`, `м’яч`, `мячь`, `дверь`, `двері`, `ball` and `door`. Select the intended object; verify English canonical name, localized meaning, variants and source. Add it, enter a local exception, exclude a variant and save. Reload and verify both the exception and exclusion. Repeat rapid query changes and keyboard selection. Disconnect the provider or use failure fixtures: manual English configuration and retry remain available. Check narrow mobile layout and long text. Test actual persistence in the existing integration fixture; do not alter real employee shifts or trigger billable AI. See tasks and feature memory for exact commands and results.
