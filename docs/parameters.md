# Параметри, які замовник затверджує до розробки

Джерело: ТЗ, розділ 18. Колонка «Рішення» заповнюється на воркшопі фази 0. Кожен затверджений параметр стає записом у `settings` або константою конфігурації.

| №   | Рішення                                 | Рекомендоване значення                             | Рішення замовника | Ключ налаштування                                       |
| --- | --------------------------------------- | -------------------------------------------------- | ----------------- | ------------------------------------------------------- |
| 1   | Майданчик і часовий пояс IANA           | вказати фактичний                                  |                   | `sites.timezone`                                        |
| 2   | Календарний місяць і/або ковзні 30 днів | планування місяць; перегляд місяць + 30 днів       |                   | `schedule.view_horizon_days`                            |
| 3   | Час денної і нічної зміни               | 08:00–20:00 / 20:00–08:00                          |                   | `shift_templates`                                       |
| 4   | Вікна приходу, початку і відходу        | налаштувати після 2–4 тижнів спостереження         |                   | `attendance.grace_minutes.*`                            |
| 5   | Правила й оплачуваність обіду і перерв  | за локальними актами і законом                     |                   | `BREAK_MINUTES`, `MEAL_MINUTES`, `SERVICE_TIME_MINUTES` |
| 6   | Перелік контрольних зон                 | мінімальний довідник ділянки або поста             |                   | `responsibility_zones`                                  |
| 7   | Хто здає і приймає спільну зону         | призначений відповідальний; інакше командна оцінка |                   | `handover.shared_zone_mode`                             |
| 8   | QR rotation / TTL                       | 30–60 с / 60–120 с                                 |                   | `QR_ROTATION_SECONDS`, `QR_TTL_SECONDS`                 |
| 9   | Поріг ескалації простою                 | 15 хвилин; безпека негайно                         |                   | `DOWNTIME_ESCALATION_MINUTES`                           |
| 10  | Нагадування про прибирання              | за 30 хвилин                                       |                   | `cleaning.reminder_minutes`                             |
| 11  | Вікно зауваження приймаючої зміни       | 15–30 хвилин від початку її зміни                  |                   | `handover.review_window_minutes`                        |
| 12  | Ракурси і якість фото                   | 3 ракурси за шаблоном зони                         |                   | `media.angles`, `media.min_resolution`                  |
| 13  | Дозвіл галереї / Mini App камери        | MVP: налаштування; суворий режим окремий етап      |                   | `media.allow_gallery`                                   |
| 14  | Строк корекції і апеляції               | корекція 24 год; апеляція 3 робочі дні             |                   | `corrections.window_hours`, `appeals.window_days`       |
| 15  | Бонусна база і версія шкал              | визначає HR і керівництво після пілоту             |                   | `bonus_rule_versions`                                   |
| 16  | Строки зберігання подій і фото          | за метою обробки і локальними вимогами             |                   | `retention.*`                                           |
| 17  | Резервний спосіб відмітки               | спільний термінал + майстер                        |                   | `attendance.reserve_methods`                            |
| 18  | Пікове навантаження                     | працівники на зміну, фото за хвилину, майданчики   |                   | вхід для навантажувального тесту                        |
| 19  | Підтвердження виходу QR                 | увімкнути, якщо є точка на виході                  |                   | `attendance.exit_qr_enabled`                            |
| 20  | Країна застосування і локальні акти     | обов'язкова юридична перевірка                     |                   | документ, не налаштування                               |

## Додаткові питання з аналізу

| Пріоритет | Питання                                            | Рішення |
| --------- | -------------------------------------------------- | ------- |
| A         | Хостинг: хмара чи on-prem                          |         |
| A         | IdP для панелі: SSO чи власний логін + TOTP        |         |
| B         | Веб-форма резервної відмітки в MVP                 |         |
| B         | Термінал: планшет чи монітор, кількість точок      |         |
| C         | Мова інтерфейсу: російська, чи потрібна українська |         |
