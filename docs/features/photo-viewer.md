# Photo viewer

Evidence photos opened from incidents and handover use the shared
photo viewer. Each displayed photo supports zoom from 100% to 500%, zoom out and reset. At an
increased scale, drag the photo to inspect details; touch screens support two-finger pinch gestures.

Keyboard: + or = enlarges, - reduces, 0 resets. Arrow keys move an enlarged photo; at the initial
scale left/right retain gallery navigation. Escape closes the viewer. Browser zoom shortcuts remain
available. Moving to another photo resets its scale and position. Two-photo comparisons have separate
zoom controls for each image.

On phones, galleries keep previous/next buttons without mounting thumbnail previews. Desktop
thumbnail navigation remains available. Zoom changes only presentation, never the stored image.
