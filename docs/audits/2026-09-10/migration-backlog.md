# Reviewable migration backlog

Baseline: `08979de`. All rows below are proposed follow-up work, not implemented by this audit.
Sizes are relative estimates: S = one narrow concern, usually below one day; M = a few focused days;
L = a larger design/verification effort that must be split before implementation. They are not promises.

Ordering follows correctness before speed. Source-inferred failures require a regression reproduction
before a fix. L1–L7 refer to the [Lean report](lean-bottlenecks.md); duration is observed workload,
not guaranteed savings. Each row is a separate reviewable PR; where remote settings are needed, the
PR contains the exact reviewed configuration and the owner applies it separately.
